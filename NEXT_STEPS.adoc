== Bugs / Correctness Issues

=== 5. Double DB lookup on delete ✅ ERLEDIGT
`BildService.java` — `delete()` lud das Bild zweimal (via `findFullPathById` + `findById`). Jetzt einmaliger `findById`-Aufruf; Pfadberechnung und DB-Löschung im selben `chain`-Schritt. Tote Hilfsmethode `findFullPathById()` und leerer Stub `rotateBild()` entfernt. Unit-Tests in `BildServiceTest` ergänzt.

=== 6. `imageVersion` is shared across all images ✅ ERLEDIGT
`Bilder.js` — `imageVersion` war ein globaler Zähler; auf pro-Bild-Map `imageVersions[bild.id]` umgestellt, sodass bei Rotation nur das betroffene Bild neu lädt.

=== 7. `bildSort` in `Bilder.js:23-30`
Both conditions compare `t1.id`/`t2.id` (not priority), so priority is effectively never used for sorting Bilder.

== Missing Features / UX Gaps

=== 17. No thumbnail/resize on upload
Full-size images are served without resizing. This can be expensive on mobile or slow connections.

=== 18. No pagination
`listForUser()` returns all Bilder/Texte at once. Performance will degrade as content grows.

=== 19. No story completion/progress indicator
The `Story` entity has no aggregated completion state. The UI cannot show how many items in a story are marked complete without iterating client-side.
