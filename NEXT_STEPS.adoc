== Missing Features / UX Gaps

=== 17. No thumbnail/resize on upload
Full-size images are served without resizing. This can be expensive on mobile or slow connections.

=== 18. No pagination
`listForUser()` returns all Bilder/Texte at once. Performance will degrade as content grows.

=== 19. No story completion/progress indicator
The `Story` entity has no aggregated completion state. The UI cannot show how many items in a story are marked complete without iterating client-side.

=== 23. `ImageSettings` in `CaptureService` einbinden
`ImageSettings.java` modelliert gphoto2-Kameraeinstellungen (Bildformat, ISO, Weißabgleich, Farbtemperatur, Farbraum) vollständig als DTO. Die Klasse ist aktuell ungenutzt — `CaptureService` löst nur blind den Auslöser aus (`gphoto2 --capture-image-and-download`), ohne Einstellungen zu setzen.

Ziel: Vor dem Snapshot per `gphoto2 --set-config` die gewünschten Einstellungen aus `ImageSettings` auf die Kamera schreiben. Entweder als feste Konfiguration in `application.properties` oder als API-Parameter beim Capture-Aufruf.

Betroffene Klassen: `CaptureService.java`, `BildService.java` (oder neue `takeBild()`-Implementierung), `ImageSettings.java`.

=== 24. DB-Passwort in Fly.io rotieren
Das Passwort `yKTSyH4aXUsrB9e` ist in der Git-History von `application.properties` enthalten (inzwischen durch `.env`-Variablen ersetzt). Das Passwort sollte rotiert werden.

Schritte:

[source,bash]
----
# 1. Verbinde mit der Postgres-App
flyctl postgres connect -a jahrbuch-generator-pg
----

[source,sql]
----
-- 2. Passwort in der DB ändern
ALTER USER postgres WITH PASSWORD 'neues_passwort';
\q
----

[source,bash]
----
# 3. Fly.io Secret aktualisieren (wird in Dockerfile.fly als $FREE_DATABASE_URL verwendet)
flyctl secrets set FREE_DATABASE_URL=postgres://postgres:neues_passwort@jahrbuch-generator-pg.flycast:5432 -a jahrbuch-generator

# 4. App neu starten
flyctl restart -a jahrbuch-generator
----

Danach lokal `.env` aktualisieren:
----
DEV_DB_PASSWORD=neues_passwort
----
